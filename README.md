## 🚀 GitHub AI App\n\nAn AI-powered GitHub App for intelligent code assistance, automated reviews, and smart suggestions.\n\n### ✨ Key Features\n- GitHub App Integration\n- Webhook Support for Real-time Events  \n- AI-powered Code Analysis\n- Automated Pull Request Reviews\n- Smart Code Suggestions\n- User Authentication & Authorization\n- MongoDB Database Integration\n- RESTful API\n- Docker Support\n\n### 🛠 Tech Stack\n\n- **Backend:** Node.js, Express.js\n- **Database:** MongoDB\n- **Authentication:** JWT\n- **GitHub Integration:** @octokit/app, @octokit/rest\n- **AI Integration:** OpenAI API (configurable)\n- **Containerization:** Docker, Docker Compose\n\n### 📋 Prerequisites\n\n- Node.js >= 18.0.0\n- npm >= 9.0.0\n- MongoDB (local or cloud)\n- GitHub App credentials\n- OpenAI API key (for AI features)\n\n### 🔧 Installation\n\n#### 1. Clone the Repository\n\n```bash\ngit clone https://github.com/yourusername/github-ai-app.git\ncd github-ai-app\n```\n\n#### 2. Install Dependencies\n\n```bash\nnpm install\n```\n\n#### 3. Setup Environment Variables\n\n```bash\ncp .env.example .env\n```\n\nEdit `.env` and add your configuration:\n\n```env\nGITHUB_APP_ID=your_app_id\nGITHUB_PRIVATE_KEY=your_private_key\nGITHUB_WEBHOOK_SECRET=your_webhook_secret\nMONGODB_URI=mongodb://localhost:27017/github-ai-app\nAI_API_KEY=your_openai_api_key\n```\n\n#### 4. Start the Application\n\n**Development:**\n\n```bash\nnpm run dev\n```\n\n**Production:**\n\n```bash\nnpm start\n```\n\n**Using Docker:**\n\n```bash\ndocker-compose up -d\n```\n\n### 📚 API Endpoints\n\n#### Health Check\n\n```bash\nGET /api/health\n```\n\n#### Authentication\n\n**Register:**\n\n```bash\nPOST /api/auth/register\nContent-Type: application/json\n\n{\n  \"username\": \"user\",\n  \"email\": \"user@example.com\",\n  \"password\": \"password123\"\n}\n```\n\n**Login:**\n\n```bash\nPOST /api/auth/login\nContent-Type: application/json\n\n{\n  \"email\": \"user@example.com\",\n  \"password\": \"password123\"\n}\n```\n\n#### GitHub Integration\n\n**Get User Repositories:**\n\n```bash\nGET /api/github/repos\nAuthorization: Bearer <token>\n```\n\n**Get Repository Details:**\n\n```bash\nGET /api/github/repos/:owner/:repo\n```\n\n**Update Repository Settings:**\n\n```bash\nPUT /api/github/repos/:owner/:repo/settings\nAuthorization: Bearer <token>\nContent-Type: application/json\n\n{\n  \"autoReview\": true,\n  \"autoFix\": false,\n  \"aiModel\": \"gpt-4\"\n}\n```\n\n#### AI Features\n\n**Get Code Suggestions:**\n\n```bash\nPOST /api/ai/suggestions\nAuthorization: Bearer <token>\nContent-Type: application/json\n\n{\n  \"code\": \"your code here\",\n  \"language\": \"javascript\",\n  \"context\": \"additional context\"\n}\n```\n\n**Generate Code Review:**\n\n```bash\nPOST /api/ai/review\nAuthorization: Bearer <token>\nContent-Type: application/json\n\n{\n  \"pullRequestId\": 123,\n  \"owner\": \"username\",\n  \"repo\": \"repo-name\"\n}\n```\n\n### 🐙 GitHub App Setup\n\n#### 1. Create GitHub App\n\n1. Go to GitHub Settings → Developer settings → GitHub Apps\n2. Click \"New GitHub App\"\n3. Fill in the app details\n4. Set webhook URL to your app's public URL (use ngrok for local development)\n5. Generate a private key\n6. Select permissions:\n   - `pull_requests` - Read & write\n   - `issues` - Read & write\n   - `contents` - Read\n   - `checks` - Read & write\n\n#### 2. Subscribe to Events\n\n- Pull request\n- Issues\n- Push\n- Pull request review comment\n\n### 💻 Development\n\n#### Running Tests\n\n```bash\nnpm test\n```\n\n#### Linting\n\n```bash\nnpm run lint\n```\n\n#### Database Migrations\n\n```bash\nnpm run migrate\n```\n\n### 📁 Project Structure\n\n```\n.\n├── src/\n│   ├── server.js           # Main server file\n│   ├── routes/             # API routes\n│   ├── middleware/         # Express middleware\n│   ├── models/             # MongoDB schemas\n│   ├── services/           # Business logic\n│   └── db/                 # Database config\n├── tests/                  # Test files\n├── .env.example            # Environment variables template\n├── Dockerfile              # Docker configuration\n├── docker-compose.yml      # Docker Compose setup\n├── package.json            # Dependencies\n└── README.md               # This file\n```\n\n### 🤝 Contributing\n\n1.
